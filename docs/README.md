# Documentation

Living documentation for Kudi AI Bank's backend platform.

- [`SETUP.md`](SETUP.md) — step-by-step local setup: installing dependencies, configuring `.env`, and running the backend and frontend together
- [`module.md`](module.md) — module build roadmap: what's built, in what order and why, and the recommended next module (Funding/Deposits) with the reasoning
- [`CODEBASE-OVERVIEW.md`](CODEBASE-OVERVIEW.md) — onboarding read: stack, entry points, module structure, auth flow, and known risks, each pointing at the relevant file
- [`FOLDER-STRUCTURE-GUIDE.md`](FOLDER-STRUCTURE-GUIDE.md) — junior-engineer folder-by-folder tour: what's app code vs. config vs. generated, entry points, obsolete/duplicated files, and a dependency map
- [`AUDIT.md`](AUDIT.md) — frontend/backend implementation gap findings
- [`API-CONTRACT.md`](API-CONTRACT.md) — authoritative frontend↔backend endpoint mapping
- `architecture/` — system architecture, ADRs, DDD bounded-context maps
- `api/` — API contracts/specifications (added as endpoints are built)
- `database/` — schema documentation, ERD references
- `deployment/` — deployment runbooks and environment topology
- `modules/` — per-module documentation as business modules are built
